## Unreleased — The charter no longer claims options exits that the live system does not run

- `TRADING_POLICY.md` said profit targets, the stop multiplier and the DTE time-stop were "live". They are implemented in `strategy_engine.check_exit` and exercised by the backtester and optimizer, but **no live component evaluates them**: an open options spread is closed only manually, by position rotation, or by expiry/assignment, and combo orders carry no broker-side exit. Backtested expectancy that assumes those exits therefore does not describe live behaviour. The status line now says so, and a test ties the document to the code in both directions, with a strict xfail that turns red the day an exit is wired in. Also added `bear_put_spread` to the leg-mapping table, which alone knew the strategy as `bear_put_debit_spread`. No behaviour change.
