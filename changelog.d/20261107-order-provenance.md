## Unreleased — Open-orders page now says who placed each order

- **New, read-only: each resting order reports the program that sent it.** `GET /api/portfolio/open-orders` (and the IBKR order read behind it) now include, per order, IBKR's own record of the sender: `client_id`, `perm_id` (IBKR's permanent order id), `order_ref` (a tag the sender may set; the app sets none today) and `account`, plus a plain label `placed_by`: `this_app` (this server's API client id), `tws_or_manual` (client id 0: orders entered in TWS / IB Gateway itself), `other_api_client` (a different program using the same account) or `unknown` (IBKR did not say). The response also reports `app_client_id` so the label can be checked by eye.
- **Why:** two open positions carried brackets at IBKR with no record anywhere in the app of having sent them. The app logs its own orders but cannot log anyone else's; IBKR stamps every order with the sender's client id, so the sender is read from the broker's record instead of inferred from silence in our own logs. `IB.placeOrder` stamps our id on the orders we place, so `this_app` is reliable.
- **Nothing existing changes.** The new keys are additions; every key the stop backfill, orphan sweep, rotation preflight and the page already read is unchanged. It places, cancels and modifies nothing, and no order is tagged differently yet.
- **Deployment:** backend restart only. No migration, no new environment variables, no frontend change. Deploy outside 09:30–16:00 ET. Then open `/api/portfolio/open-orders` while signed in and read `placed_by` for each order.
