## Unreleased — tab, filter and range pickers are flat, like the main tab bar

- The Trade Desk sub-tabs (Overview, Desk signals, Positions, …), chart timeframes (5M/15M/…), dashboard ranges, and the tab/filter pickers on Journal, Intel, Income Matrix, Options Flow, Guardrails and Alerts no longer look like raised 3D keys. They are flat with an underline on the selected one, matching the main tab bar.
- Action buttons (Close, Run signal cycle, Halt) and the Manual/Copilot/Autopilot mode switch keep the raised style.

Frontend only: no backend restart, no migration, no new environment variables.
